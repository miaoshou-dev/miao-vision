你说目标，Agent 做完剩下的。

放入文件，用一句话描述你要讲清楚什么。Miao Vision 会完成分析、校验和渲染。

01放入本地 CSV、Excel、JSON 或 Markdown

03得到可分享的 HTML、PDF 或 PNG 文件
